# 🎬 AI Video Script Studio

A lightweight tool that turns a single topic into a full video script using OpenAI GPT-4.1.  
Generates titles, descriptions, hooks, structured sections, and CTAs for YouTube, TikTok, and Reels.

## ✨ Features
- Full script generation from one prompt
- Short-form & long-form formats
- Clean UI (Next.js + Tailwind)
- Strict JSON output (stable structure)
- Fast, simple, creator-friendly

## 🛠 Tech Stack
Next.js · TypeScript · TailwindCSS · OpenAI API

## 🚀 Run locally
```bash
npm install
npm run dev
